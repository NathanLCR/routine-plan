RS — Week 3: NPR Scoring Methods & PageRank

Focus

This session moved from theory (W2) to implementation: four scoring functions for aggregate-opinion non-personalised recommenders, followed by PageRank as a graph-authority approach. The lecturer forces you to rank the same dataset with each method so the failure modes are impossible to ignore — raw difference rewards volume, raw proportion rewards zero-evidence items, and only Wilson LB handles both. PageRank extends ranking from vote counts to structural link authority, setting up graph-based recommenders.

Key Concepts

  • Aggregate opinion recommender — ranks items using collective up/down signals from the full user base; no individual history needed
  • Score = U − D (positive minus negative) — rewards high absolute vote counts; high-volume mediocre items can outrank niche but well-received ones
  • Score = U / N (proportion positive) — fixes volume bias but treats 1/1 identically to 10,000/10,000; zero-evidence items contaminate top-N lists
  • Wilson Lower Bound (WLB) — confidence interval lower bound for the true positive proportion; penalises items with few votes by shrinking their score toward the prior
  • PageRank — assigns authority to nodes (pages/items) by propagating scores along directed edges (links); pages linked to by high-authority pages gain more score
  • Damping factor (d) — probability (0–1) of following a link rather than jumping randomly; controls how much authority propagates vs. dissipates; default 0.85
  • Convergence (ε) — iteration stops when max|new_score − old_score| < ε; typical threshold 1e-8

Notes (live capture)

Why four methods?

  • Each fixes one failure mode introduced by the previous method
  • Progression: total votes → net score → proportion → Wilson LB
  • Point of the exercises: expose each method's blind spot on the same dataset, not just learn a formula

Score = U − D failure:

  • Item 8 (3210 up, 10 down) wins — fine
  • Item 27 (2000 up, 1000 down) ranks 2nd — 33% negative rate, yet beats items with near-perfect rates
  • High raw score masks poor quality; volume drowns out quality

Score = U / N failure:

  • Items 2, 20, 21, 23 all score 1.000 — but item 2 has only 1 vote (1 up, 0 down)
  • A single up-vote article ranked identical to 90-vote article with zero negatives
  • Top-N list becomes polluted with near-zero-evidence items

Wilson Lower Bound fix:

  • Item 2 (1 up, 0 down, 100%) → WLB 0.207
  • Item 23 (90 up, 0 down, 100%) → WLB 0.959
  • Item 8 (3210 up, 10 down, 99.7%) → WLB 0.994 — correctly wins
  • Ranking stabilises: high confidence + high positive rate wins; uncertainty is punished

PageRank mechanics:

  • Graph: keys = pages, values = list of pages they link to
  • Each page starts with score 1.0
  • Each outgoing link distributes the page's score equally across its targets
  • Damping factor prevents score draining into sink nodes (pages with no outgoing links)
  • Exercise: adding many fake pages linking only to one page inflates that page's score — demonstrates why Google needed spam countermeasures

Damping factor effects:

  • d = 1.0: pure link-following; sink nodes drain the system; can fail to converge
  • d = 0.85: standard; small random-jump floor keeps scores bounded
  • Lower d → more random jumps → scores converge toward uniform; topology matters less

Larger dataset (1000 random links, 30 articles):

  • Scores range 0.832 (article 2) to 1.174 (article 24)
  • No inherent quality signal — purely structural; most-linked-to wins
  • Spread is narrow because graph is dense and random; real web graphs are power-law → much more extreme spread

Math / Code

import pandas as pd
import numpy as np

# ── Wilson Lower Bound ──────────────────────────────────────────────────────
def wilson_lower_bound(up, total, z=1.96):
    p_hat = up / total
    return (
        p_hat + z**2/(2*total) - z * np.sqrt((p_hat*(1-p_hat) + z**2/(4*total)) / total)
    ) / (1 + z**2/total)

# Applied to a DataFrame
df['wilson_lower_bound'] = wilson_lower_bound(df['up'], df['total_votes'])

# ── PageRank ────────────────────────────────────────────────────────────────
def pagerank(graph, damping_factor=0.85, epsilon=1e-8):
    scores = {page: 1.0 for page in graph}
    out_links = {page: len(links) for page, links in graph.items()}
    while True:
        new_scores = {
            page: (1 - damping_factor) + damping_factor * sum(
                scores[link] / out_links[link] for link in graph[page]
            )
            for page in graph
        }
        if max(abs(new_scores[p] - scores[p]) for p in graph) < epsilon:
            break
        scores = new_scores
    return scores

# Build graph from a DataFrame of (article_linking, linked_article) pairs
graph = (
    df.groupby('article_linking')['linked_article']
      .apply(set).apply(list).to_dict()
)
scores = pagerank(graph)
pd.Series(scores).sort_values(ascending=False)

Wilson LB formula reference:

WLB = (p̂ + z²/2n − z·√((p̂(1−p̂) + z²/4n)/n)) / (1 + z²/n)
  where p̂ = up/n,  z = 1.96 (95% CI),  n = total votes

Flashcards (SR)

  • Q: What failure does Score = U − D have that U/N fixes?

    • A: U − D rewards high absolute vote counts; high-volume mediocre items outrank niche well-received ones. U/N normalises by total votes.

  • Q: What failure does U/N have that Wilson LB fixes?

    • A: U/N treats 1 vote at 100% identically to 10,000 votes at 100%. Wilson LB penalises low-sample items by shrinking their score toward the uncertainty prior.

  • Q: Write the Wilson Lower Bound formula.

    • A: (p̂ + z²/2n − z·√((p̂(1−p̂) + z²/4n)/n)) / (1 + z²/n), where p̂ = up/n, z = 1.96, n = total votes.

  • Q: What does the PageRank damping factor control?

    • A: The probability of following a link (vs. jumping to a random page). Prevents score draining into sink nodes and ensures convergence. Typical value: 0.85.

  • Q: How does PageRank update a page's score each iteration?

    • A: score[page] = (1 − d) + d · Σ (score[link] / out_links[link]) for each link in graph[page].

  • Q: Why does adding many fake pages that link to one target page inflate its PageRank?

    • A: Each fake page distributes its score to the target; the target accumulates many small contributions. This is the link-spam attack PageRank was later hardened against.

  • Q: Name the four scoring methods covered and one failure mode each.

    • A: (1) Total votes — no quality signal. (2) U − D — volume over quality. (3) U/N — zero-evidence items contaminate top-N. (4) Wilson LB — interpretable but assumes binomial; ignores rating magnitude.

  • Q: What structural assumption does PageRank make that vote-based methods don't?

    • A: PageRank requires a directed graph (items linked to other items). Vote methods only need per-item aggregate counts — no item-to-item relationship needed.
