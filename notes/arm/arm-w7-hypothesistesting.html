The 7 steps (slide 2 — memorise)

  1. Write down the null hypothesis (H0)
  2. Write down the alternative hypothesis (H1)
  3. Calculate the test statistic (z, t, f, χ²)
  4. Find the critical value from the tables
  5. Compare calculated value to critical value
  6. Accept or reject H0 based on step 5
  7. Interpret step 6 in plain English — no "accept/reject hypothesis" jargon

Which test to use

| Test | When | df | |---|---|---| | z-test | Population mean and SD known; large samples (>30). Assumes population is normal and σ known. | — | | 1-sample t-test | Compare a sample mean to a known population mean (e.g. new drug vs known baseline). Small samples (<30), σ unknown (the usual case). | n − 1 | | 2-sample t-test (independence test) | Compare means of two independent groups (e.g. two mouse treatment groups). | n1 + n2 − 2 | | Paired t-test | Compare means within paired/dependent data (e.g. blood pressure before vs after treatment on the same people). | n − 1 (n = number of pairs) | | ANOVA (F-test) | Compare means of 3+ groups. One-way = 1 independent variable; two-way = 2; etc. | DFB = k − 1; DFW = N − k |

Formulas

One-sample t: t = (X̄ − μ0) / (s / √n)

Two-sample t: t = (X̄1 − X̄2) / √(s1²/n1 + s2²/n2)

where X̄ = sample mean, s = standard deviation, n = sample size.

Reading the t-table: compute df (v = n − 1), then the column A = (1 − CI)/2 for a two-tailed test. E.g. 95% CI → A = 0.025; df = 6 → t = ±2.447. Deck example: 5-sample dataset → df = 4, 95% → ±2.776.

Decision rule (t): accept H0 if calculated t falls between −t_crit and +t_crit; otherwise reject.

ANOVA F-ratio: F = variability between groups / variability within groups = MSB/MSW.

  • H0 true → both estimates are just random error → F ≈ 1.
  • H0 false → numerator carries random error + treatment effect → F > 1 (much larger for big effects).
  • H0: μ1 = μ2 = μ3 (all group means equal); H1: at least one differs.
  • Decision rule (F): calculated F > table F → reject H0 (slide in red, full page — the one thing he wanted remembered).
  • F-table (Table C in appendix): light number = 0.05 level, dark = 0.01. Observed F < light → p > .05; between → p < .05; above dark → p < .01.

The conceptual exercise (slide 15, from Witte's Statistics): four datasets of 3 groups × 4 obs — (a) all values identical → zero variability everywhere, no test needed; (b) groups differ, zero within-group spread → huge F, reject; (c) group means close, large within-group spread → F small, accept; (d) means far apart relative to spread → reject. Point: F is a ratio — a mean difference only counts relative to noise.

Worked answers to the slide exercises (mine — verified numerically)

t-test questions (slides 8, 10)

Q1 — 2-sample: A (55, s=8), B (60, s=10), n=25 each, α=0.01. t = (55−60)/√(64/25 + 100/25) = −5/2.561 = −1.95. df = 48, crit ≈ ±2.68. |t| < crit → accept H0. Plain English: no evidence the two biomaterials differ in tensile strength. (Slide 9 confirms: 1.95, accept.)

Q2 — 1-sample vs 0: n=20, X̄=12, s=1.2, α=0.05. t = 12/(1.2/√20) = 44.7. df = 19, crit ±2.093. Reject H0 emphatically. The post-processing technique produces a real improvement.

Q3 — 2-sample: X (30, s=2.6, n=30), Y (28, s=5, n=35), α=0.05. t = 2/√(0.225 + 0.714) = 2.06. df = 63, crit ≈ ±2.00. |t| just exceeds crit → reject H0 (marginal — worth saying so in an exam). Biomaterial X has higher layer adhesion, but barely significant.

Q4 — 2-sample: A (5, s=1.5), B (6, s=2), n=30 each, α=0.05. t = −1/√(0.075 + 0.133) = −2.19. df = 58, crit ≈ ±2.00. Reject H0. The species grow at different rates.

Q5 — 1-sample vs 0: n=25, X̄=8, s=2, α=0.01. t = 8/(2/5) = 20. df = 24, crit ±2.797. Reject H0. The fertilizer genuinely raises nutrient levels.

Q6 — 2-sample: X (40, s=3.5, n=20), Y (35, s=4.5, n=25), α=0.02. t = 5/√(0.6125 + 0.81) = 4.19. df = 43, A = 0.01 → crit ≈ ±2.42. Reject H0. Tree type X has longer roots.

ANOVA questions (slides 18–19)

Q1–Q3 are under-specified as written — they give MSB/MSW ("SSB"/"SSW", loosely labelled) but no observations per group, so DFW can't be computed and no critical F can be looked up. Presumably resolved verbally in class. What can be done: Q1 F = 200/80 = 2.5; Q2 F = 300/50 = 6 (DFB = 4); Q3 F = 180/60 = 3. (Q1 and Q3 also contradict themselves: "three fertilizers/light conditions… four groups". If a replicate count surfaces from classmates, plug into DFW = N − k and read Table C.)

Q4 — 3 medications × 10 participants: DFB = 2, DFW = 30 − 3 = 27. Critical F(2,27) at 0.05 = 3.35. (The question only asks for the critical value.)

Q5 — 5 treatments × 4 replicas: DFB = 4, DFW = 20 − 5 = 15. Critical F(4,15) at 0.01 = 4.89 (dark number). Calculated F = 12.2 > 4.89 → reject H0. At least one chemical treatment changes fungi yield.

Full worked template worth copying for the exam: RQ → H0: μ0 = μ24 = μ48, H1: H0 false → decision rule: reject at 0.05 if F ≥ 5.14 (df_between = 2, df_within = 6) → F = 7.36 → reject → interpretation: hours of sleep deprivation affect mean aggression scores.
