Key Concepts

  • Sequential model ≠ sequential data. A sequential model is any ANN/feed-forward/DL architecture (the Keras Sequential you import from TensorFlow). Sequential data is data acquired across time where order carries meaning: time series (stock close price), text/sentences (tokens — reorder them and you lose the sentence), speech (tight relationship with text), video frames, sensor readings (series configuration). "Time-series data" specifically = relational sequential data (e.g. stock market).
  • Order is load-bearing → you cannot random-sample the split. Because rows are time-dependent, random train/test sampling violates the order and is invalid. For sequential data there is effectively one valid split (chronological).
  • Traditional NN assumes rows are independent; RNN assumes they're dependent through time. In an MLP/feed-forward net, the previous row has nothing to do with the current one. In a time series, the current value is a function of previous values (today's Tesla close depends on yesterday's). RNNs exist to capture temporal patterns = time-dependent patterns learned from historical data.
  • Hidden state = memory. The recursion in the hidden layer stores past information. Human-memory analogy: h_{t-1} (yesterday), h_{t-2} (2 days ago), etc., combined.
  • Recursion order. Simple RNN = first-order: h_t = f(h_{t-1}). Second-order: h_t = f(h_{t-1}, h_{t-2}) — e.g. S3 ← S2 and S1, S4 ← S3 and S2 (no S4←S1 link). Higher order = more memory = more accurate but more complex. DL keeps first order to avoid piling on complexity. Direct parallel to first/second-order Markov models in RL (state-based models).
  • Weight sharing across time (time-invariant weights). The same weight set W is reused at every timestep (W at t=0, t=1, t=2…), not W_t per step. This is critical for computational efficiency — far fewer unique weights to update than time-variant weights would need.
  • Simple RNN is short-term only. It only reaches back to h_{t-1} → good for short sequential dependency, weak on long-range context. In "I love AI", at "AI" a simple RNN really only connects to "love"; long dependency would also connect "AI" back to "I".
  • Vanishing / exploding gradient. Training backprops gradients through time; repeated multiplication (the nature of the weight-update equation) drives the loss-gradient w.r.t. the hidden values toward 0 (vanishing) or blows it up (exploding) → inefficiency and inaccuracy. Early-timestep information is lost. This is the reason LSTM exists.
  • LSTM = RNN + cell state + 3 gates. Adds a cell state C_t (long-term memory) alongside the hidden state h_t (short-term memory), controlled by three gates that learn what to keep, what to forget, what to output: forget gate, input gate, output gate. Handles long-term dependency much better; still some residual vanishing-gradient risk but far less.
  • GRU — deferred. Named as the third model; "what is GRU, and how does it differ from LSTM (structure, math, application)" to be covered around the presentations.
  • Multimodal / fusion (came out of Nathan's feedback). When input has two modes (text + image), use two branches (CNN for image, LSTM/bidirectional for text) and fuse them into one pipeline. "Fusion" is itself an advanced topic (there's a journal, Information Fusion).

Notes — technical lecture (paraphrased)

RNN forward equations (reconstructed to standard form):

h_t = tanh( W_xh · x_t  +  W_hh · h_{t-1}  +  b_h )      # phi = tanh (common, not mandatory — depends on data)
y_t = W · h_t + b                                        # output: LINEAR activation (y_t = T), not ReLU
  • Lecturer stressed the output layer here uses a linear activation, and the hidden recurrence typically tanh — but activation choice is dataset-dependent; keep the general form with an activation slot.
  • Stock-market framing question: if your series is one column (close price), how do you construct X and Y? — he posed this as the key question to answer before anything else (windowing the series into input→target).
  • Text example "I love AI": index by time → x1=I, x2=love, x3=AI; the hidden state carries context forward so "love" is interpreted relative to "I". Reordering tokens destroys context.

LSTM gate machinery (reconstructed):

f_t = σ( W_f·[h_{t-1}, x_t] + b_f )          # forget gate  — what to discard (≈0 forget / ≈1 keep)
i_t = σ( W_i·[h_{t-1}, x_t] + b_i )          # input gate   — what new info to store
C̃_t = tanh( W_c·[h_{t-1}, x_t] + b_c )       # candidate cell
C_t = f_t * C_{t-1} + i_t * C̃_t              # cell update  — TWO mult + ONE sum; recursion in LONG-term memory
o_t = σ( W_o·[h_{t-1}, x_t] + b_o )          # output gate
h_t = o_t * tanh( C_t )                       # hidden update — recursion in SHORT-term memory
  • Gates use sigmoid (the blue σ blocks); candidate and the cell→hidden path use tanh. Combination of gate outputs is element-wise multiplication.
  • Mental model: C_t = long-term memory line (the recursion C_{t-1}→C_t), h_t = short-term memory derived from the cell through the output gate. The forget gate is effectively a binary keep/forget on incoming info.
  • Variants flagged: bidirectional LSTM, ConvLSTM (CNN+LSTM hybrid), temporal CNN, transformer-based.
