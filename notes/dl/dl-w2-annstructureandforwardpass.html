DL — Week 2: ANN Structure & Forward Pass

Focus

Building the ANN forward pass node-by-node: the distinction between the transfer function (weighted sum / pre-activation T) and the activation function (A(T)), why hidden layers use ReLU but classification outputs must use sigmoid/softmax, and how weights are initialised before training. Feed-forward only today; loss, optimiser, learning rate and backpropagation are deferred to the next class. Lecturer's sharpest warning: students keep wiring ReLU into the output layer of a classifier — its [0, ∞) range gives values like 5 that cannot be read as a class probability, so predictions are inconsistent. Use sigmoid/softmax at the output.

Key Concepts

  • Transfer function T — the pre-activation: weighted sum of inputs incl. bias, T = Σ wᵢxᵢ. One formula, always the same.
  • Activation function A — non-linearity applied to T; node value = A(T). Choice depends on layer/task (ReLU, sigmoid, softmax, tanh).
  • Fully connected layer — every node in one layer connects to every node in the next; each connection carries one weight.
  • Bias node — x₀ = 1 always; contributes w₀·1 = w₀. Kept (not dropped) because backprop must differentiate w.r.t. it.
  • Weight — a real-valued parameter, unconstrained (negative, zero, positive all valid). Notation w^(layer)_{i,j}: superscript = layer, first index = source/input node, second index = destination node.
  • ReLU — max(0, T); hidden-layer default. Doesn't bound hidden activations to [0,1]; range [0, ∞).
  • Sigmoid / softmax — output activations for classification; squash to [0,1] so outputs read as probabilities → argmax gives the predicted class.
  • Epoch — one full forward+backward pass over the training data; the lecturer's stated "important hyperparameter" (see flag below for the precise definition).
  • Weight initialisation kernels — Normal (np.random.randn, ties to StandardScaler) or Uniform (np.random.rand, ties to MinMaxScaler).

Notes (live capture)

Network topology (worked example):

  • Input: x₀ (bias = 1), x₁ … x_K. Each x_k is a feature = column k of the CSV; one sample = one row processed at a time.
  • Hidden layer: H1, H2. Output layer: O1, O2 → binary classification (Class 1 vs Class 2).
  • Fully connected throughout; bias added at every layer, not just the input.

Transfer vs activation:

  • For each node: first compute T (transfer = weighted sum incl. w₀), then apply A(T) (activation).
  • H_j = A( Σ_{i=0}^{K} w^1_{i,j} · x_i ). Different weights → H1 ≠ H2 even though they share the same inputs.
  • Output nodes repeat the same idea on the hidden-layer outputs to produce O1, O2.

Activation choice by layer:

  • Hidden → ReLU. Reason: hidden node values shouldn't be capped; they can be any real value depending on the computation. ReLU(T) = T if T>0 else 0.
  • Output (classification) → sigmoid σ(T) = 1/(1+e^{-T}) (binary) or softmax e^{T_i}/Σ_j e^{T_j} (multi-class). Both ∈ [0,1]; softmax also sums to 1. Prediction = argmax of the output probabilities.
  • This mirrors logistic regression exactly — same logistic function. Difference between ANN and logistic regression = the model structure (ANN stacks hidden layers; logistic regression is a single transformation). This was the lecturer's closing question.

Weight initialisation:

  • Two probabilistic kernels: Normal distribution or Uniform distribution.
  • Normal (randn) ↔ StandardScaler logic: standardised data has mean 0 and ~99.7% of values in [-3, 3] (see stats flag).
  • Uniform (rand) ↔ MinMaxScaler logic: values in [0, 1].
  • Weight count, layer 1: (K+1) weights per hidden node (incl. bias) × number of hidden nodes. Worked example K=10, 2 hidden nodes → 2·(K+1) = 22 weights → np.random.randn(22).

Training-phase logic (the "why compute output if we know the label?" question):

  • In training the labels are known. We still run the forward pass because we're estimating the weights: forward pass → predicted probability → compare to known label → (next class) backprop updates weights.
  • Example: flatten an image into features, true label = "dog"; the network computes P(class) so it can be compared against the label and corrected.

Forward pass procedure:

  1. Initialise/simulate weights (randn or rand).
  2. Compute T̂ then A(T̂) for hidden layer → H1, H2.
  3. Repeat hidden→output → O1, O2.
  4. Apply sigmoid/softmax → probabilities → argmax → prediction.

Math / Code

import numpy as np

# --- Forward pass for one sample through a 1-hidden-layer ANN (binary classification) ---
def relu(z):      return np.maximum(0.0, z)
def sigmoid(z):   return 1.0 / (1.0 + np.exp(-z))
def softmax(z):   e = np.exp(z - z.max()); return e / e.sum()   # stable softmax

K, H = 10, 2                      # features, hidden nodes
x  = np.concatenate(([1.0], np.random.rand(K)))   # x0=1 bias + K features

# Weight init — Normal (StandardScaler logic) or Uniform (MinMaxScaler logic)
W1 = np.random.randn(H, K + 1)    # hidden weights incl. bias column  -> 2 x 11 = 22 values
W2 = np.random.randn(2, H + 1)    # output weights incl. bias

# Transfer (T) then Activation (A)
T_hidden = W1 @ x                 # weighted sum  T = Σ w_i x_i
H_out    = relu(T_hidden)         # hidden activation: ReLU, range [0, inf)

h = np.concatenate(([1.0], H_out))   # add bias for next layer
T_out    = W2 @ h
proba    = softmax(T_out)         # output activation -> probabilities, sum to 1
pred     = int(np.argmax(proba))  # predicted class

Core formulas: transfer T = Σ_{i=0}^{K} wᵢxᵢ · ReLU max(0,T) · sigmoid 1/(1+e^{-T}) · softmax e^{Tᵢ}/Σⱼe^{Tⱼ}.

Flashcards (SR)

  • Q: Difference between the transfer function and the activation function in an ANN node?

    • A: Transfer = weighted sum of inputs incl. bias (T = Σwᵢxᵢ), the pre-activation. Activation = non-linearity applied to T; node output = A(T).

  • Q: Why must a classification output layer use sigmoid/softmax rather than ReLU?

    • A: ReLU's range is [0, ∞) (e.g. 5), which can't be read as a probability. Sigmoid/softmax squash to [0,1] so outputs are class probabilities → argmax gives the prediction.

  • Q: Why keep the bias node (x₀ = 1) explicit even though x₀·w₀ = w₀?

    • A: So backpropagation can differentiate the loss with respect to w₀ and update it like any other weight.

  • Q: One-sentence difference between logistic regression and an ANN?

    • A: Same logistic/sigmoid function — the difference is the model structure (ANN stacks hidden layers; logistic regression is a single transformation).

  • Q: What are the two weight-initialisation kernels and their scaler analogues?

    • A: Normal (np.random.randn, ↔ StandardScaler, mean 0, ~[-3,3]) and Uniform (np.random.rand, ↔ MinMaxScaler, [0,1]).

  • Q: Softmax formula for output node i?

    • A: e^{Tᵢ} / Σⱼ e^{Tⱼ} — each value ∈ [0,1], all sum to 1.

Flags / Corrections (verify before the exam — lecturer's stats were loose)

  • "99.95% within ±3 by Chebyshev" is wrong on two counts. The ~99.7% within 3σ figure is the empirical rule (68–95–99.7) for the normal distribution, not Chebyshev. Chebyshev guarantees only ≥ 88.9% within 3σ for any distribution. And CLT (sampling distribution of the mean) was invoked incorrectly here — it's not what gives the spread of standardised data. Use the right name in an assessment.
  • "SHAP / interpretability is less than 6 months old" — false. SHAP (Lundberg & Lee) is from 2017. The emphasis on interpretability is current, but the dating is wrong.
  • "Feed-forward + backprop = one epoch" — imprecise. An epoch = one full pass over the entire training set; with mini-batches it contains many forward/backward passes. A single forward+backward pair is an iteration/step, not an epoch.
