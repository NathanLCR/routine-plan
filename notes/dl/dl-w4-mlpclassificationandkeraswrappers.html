DL — Week 4: MLP Classification, One-Hot Encoding, Keras Wrappers, and Model Evaluation

Focus

This lecture moved from ANN mechanics into using MLPs for classification in Keras. The key shift is target encoding: multi-class labels must be encoded into class vectors, the output layer must match the number of classes, and the loss/activation pair must fit the task. The lecture also showed how to package Keras models for cross-validation and hyperparameter search, but the notebook examples mix several APIs and a few weak design choices — useful for learning, not a production template.

---

Key Concepts

  • Categorical target — a label variable with discrete classes, e.g. Iris species.
  • Label encoding — converts string classes to integers before further processing.
  • One-hot encoding — converts integer class IDs into dummy vectors, one column per class.
  • Sequential — Keras model container that stacks layers in order.
  • Dense layer — fully connected layer; each output node connects to every input from the previous layer.
  • input_dim / input_shape — defines how many input features the first layer expects.
  • Hidden layer activation — usually ReLU for MLP hidden layers.
  • Output activation — sigmoid for binary classification, softmax for mutually exclusive multi-class classification.
  • categorical_crossentropy — loss for one-hot multi-class classification.
  • binary_crossentropy — loss for binary classification with a sigmoid output.
  • KerasClassifier / SciKeras — wrapper that makes Keras models usable with scikit-learn tools.
  • Cross-validation — evaluates model stability across multiple train/test splits.
  • Grid search — brute-force search over hyperparameter combinations.

Notes (live capture)

Classification framing:

  • For classification, the number of output nodes must match the number of classes.
  • If the target has 5 classes, use 5 output nodes.
  • A categorical label must be turned into a machine-readable representation before training.
  • Transcript example: Iris species → LabelEncoder → to_categorical().

Encoding workflow:

  • First map class labels to integers with LabelEncoder.
  • Then convert integers to dummy vectors with to_categorical.
  • The lecture treated this as the standard route for multi-class ANN classification.
  • The logic is simple: the network learns probabilities for each class, not raw text labels.

Keras model structure:

  • Sequential was the main model constructor.
  • Example baseline: one hidden layer with 8 ReLU nodes, output layer with 3 softmax nodes.
  • For Iris, input dimension is 4 because each row has 4 features.
  • The output layer does not need a separate input_dim when the previous layer already defines the flow.
  • The lecture repeatedly emphasised that Dense means a fully connected computation step.

Activation choices:

  • Hidden layers: ReLU is the default because it allows positive activations and keeps the network usable.
  • Output layer for multi-class: softmax.
  • Output layer for binary: sigmoid.
  • Softmax gives a probability distribution over classes.
  • ReLU at the output is wrong for classification because it does not produce class probabilities.

Loss and optimiser:

  • Multi-class one-hot target + softmax output → categorical_crossentropy.
  • Binary target + sigmoid output → binary_crossentropy.
  • Optimiser used in the examples: Adam.
  • The lecture framed backprop as the mechanism that updates weights after the forward pass.

Cross-validation and wrappers:

  • KerasClassifier was used to make Keras models compatible with scikit-learn cross-validation.
  • cross_val_score was used to estimate performance more robustly than a single split.
  • The notebook then pushed into repeated runs / k-fold evaluation and model comparison.
  • A later example used GridSearchCV to tune batch_size and epochs.

Worked examples in the notebook:

  • Iris: 3-class classification with one-hot labels.
  • Pima Indians diabetes: binary classification with 8 features, 1 sigmoid output, binary cross-entropy.
  • Cancer diagnosis: 30 features, 2-class softmax output, categorical cross-entropy, cross-validation, then hyperparameter search.
  • Another example compared ANN against logistic regression / Naive Bayes style baselines.

Model summary / parameter count:

  • The lecture used model.summary() to interpret the number of trainable parameters.
  • In a dense layer, parameters are basically weights plus biases.
  • This is the sanity check for whether the network structure matches the feature count and class count.

Evaluation discipline:

  • The transcript mentions recall as a target metric in at least one exercise.
  • That matters: accuracy alone can hide class imbalance.
  • Cross-validation is useful, but only if the model and labels are set up consistently.

Math / Code

# Multi-class target encoding workflow
from sklearn.preprocessing import LabelEncoder
from keras.utils import to_categorical

encoder = LabelEncoder()
y_int = encoder.fit_transform(y)
y_onehot = to_categorical(y_int)
# Iris-style MLP classifier
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Dense

model = Sequential()
model.add(Dense(8, input_dim=4, activation='relu'))
model.add(Dense(3, activation='softmax'))
model.compile(
    loss='categorical_crossentropy',
    optimizer='adam',
    metrics=['accuracy']
)
# Binary classification variant
model = Sequential()
model.add(Dense(12, input_shape=(8,), activation='relu'))
model.add(Dense(1, activation='sigmoid'))
model.compile(
    loss='binary_crossentropy',
    optimizer='adam',
    metrics=['accuracy']
)
Dense-layer parameter count:

parameters = (n_inputs + 1 bias) × n_outputs

Example:
- 4 inputs -> 8 hidden nodes = (4 + 1) × 8 = 40 parameters
- 8 hidden nodes -> 3 outputs = (8 + 1) × 3 = 27 parameters

Flashcards (SR)

  • Q: Why do multi-class labels need one-hot encoding?

    • A: Because the network output is a vector of class scores/probabilities, one node per class.

  • Q: When should you use softmax?

    • A: For mutually exclusive multi-class classification.

  • Q: When should you use sigmoid?

    • A: For binary classification, or multi-label outputs where each class is independent.

  • Q: Which loss pairs with softmax + one-hot labels?

    • A: categorical_crossentropy.

  • Q: Which loss pairs with sigmoid + binary labels?

    • A: binary_crossentropy.

  • Q: What does KerasClassifier do?

    • A: Wraps a Keras model so scikit-learn tools like cross_val_score and GridSearchCV can use it.

  • Q: Why use cross-validation?

    • A: To estimate model performance more reliably than a single train/test split.

  • Q: What is the main job of model.summary()?

    • A: To verify the layer structure and parameter count.

  • Q: What is the common hidden-layer activation in an MLP classifier?

    • A: ReLU.

  • Q: What is the key warning about classification outputs?

    • A: The output layer must match the class structure and metric; otherwise the model can look valid while being conceptually wrong.
