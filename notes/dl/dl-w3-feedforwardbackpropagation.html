DL — Week 3: Feedforward Networks, Activation Functions, and Backpropagation

Focus

This class is the missing bridge between “ANN as a diagram” and “ANN as executable training code”. The lecturer reviewed nodes/layers/architectures, then drilled into transfer values, activation functions, forward propagation, loss, optimisers, learning rate, epochs, and manual backpropagation. The sharp warning: activation/loss/metric choices are not cosmetic; they must match the target variable and task type, otherwise the network can produce invalid outputs such as negative prices or unusable class scores.

Key Concepts

  • Artificial neuron / node — computes a transfer value from weighted inputs plus bias, then applies an activation function.
  • Layer — a group of nodes; basic ANN structure is input layer → hidden layer(s) → output layer.
  • Hidden layer — intermediate representation layer; CNNs add convolution layers, RNNs add recurrence inside hidden layers, transformers keep the layer idea but change the mathematical mechanism.
  • Transfer value — weighted sum plus bias: T = Σ(w_i x_i) + b.
  • Activation function — maps the transfer value into a node value; its range determines whether the output is suitable for regression/classification.
  • Feedforward / forward propagation — computes hidden/output node values from inputs and current weights.
  • Loss function — objective measuring mismatch between actual and computed outputs; MSE for regression, cross-entropy for classification.
  • Backpropagation — updates weights by propagating error/gradients from output layer back through hidden layers.
  • Optimiser — algorithm used to update weights; SGD and Adam were mentioned, with Adam used in the Keras example.
  • Learning rate — hyperparameter controlling update step size; examples discussed: 0.001 and 0.01.
  • Epoch — repeated pass/training iteration; the scratch example used 500 epochs.
  • MLP / FFNN / BPNN — in this lecture, MLP is treated as feed-forward network plus backpropagation mechanics.

Deep learning as a subfield of machine learning:

  • Lecturer frames neural networks/deep learning as a subfield of ML: add hidden layers to a GLM-like weighted-input structure and you move toward neural networks.
  • Deep learning is useful for complex/unstructured data: image classification, text mining, audio processing, and time-series analysis.
  • GPU matters for real-world-sized datasets; for coursework exercises, dataset size can be reduced so normal compute is enough.
  • The course sequence is moving from relational/tabular data to images and more advanced architectures.

Network structure:

  • Core ANN: input layer, one or more hidden layers, output layer.
  • Multiple hidden layers still remain “hidden layers”; depth increases parameters and representational capacity.
  • Bias must be included when computing nodes; in scratch code this often appears as an extra weight (number_of_inputs + 1).
  • CNN: adds convolutional layers to the neural-network idea.
  • RNN: keeps input/hidden/output layers but adds recurrence/closed loop in hidden state; hidden value depends on current input plus previous hidden value.
  • Transformers: still layered networks, but with different mathematical formulation.

Transfer and activation:

  • For each node, compute the transfer value first: weighted inputs + bias.
  • Then apply activation: node value = f(T).
  • Transfer function is basically fixed as weighted summation; the variable design choice is the activation function.
  • Activation choice must reflect task and target range:
  • Positive-only target → ReLU-style output can be appropriate.
  • Target can be negative, e.g. temperature → ReLU output is biased/invalid because it cannot predict below zero.
  • Classification → output should behave like probabilities, so sigmoid/softmax are the usual output-layer choices.

Activation functions discussed:

  • Linear: f(T) = T. Weak default because it can produce negative outputs and stacked linear layers do not add useful non-linearity.
  • Sigmoid: 1 / (1 + e^-T), range (0, 1). Used for probability-like outputs, especially binary classification.
  • Binary threshold: converts probability-like output to 1/0, e.g. > 0.5 → 1, otherwise 0. This is decision logic, not a real activation family to over-focus on.
  • Tanh: range (-1, 1). Useful when values can be negative; can be used in hidden layers or regression-style output after scaling/inverse scaling.
  • ReLU: max(0, T). Popular for hidden nodes; suitable for positive regression outputs, but invalid if target can be negative.
  • Leaky ReLU: keeps positive T unchanged; for T <= 0, returns aT, so negative values are reduced rather than zeroed.
  • Softplus: log(1 + e^T). Smooth positive alternative to ReLU.
  • Softsign: T / (1 + |T|), range approximately (-1, 1).
  • Softmax: e^{T_i} / Σ_j e^{T_j} across output nodes. Used for multi-class classification; prediction is class with highest probability.

Backpropagation theory:

  • Start from actual output y and computed output ŷ from feedforward.
  • Loss function compares them. For regression, lecturer used MSE-style objective.
  • Since ŷ depends on weights, loss is a function of weights.
  • Take derivative/gradient of loss with respect to each weight.
  • Update each weight in each epoch using the gradient-descent pattern:
  • new_weight = old_weight - learning_rate * gradient
  • The lecturer emphasised the update happens for all connections/layers, moving backward from output layer toward earlier hidden layers.

Keras/TensorFlow implementation example:

  • Model definition uses Sequential.
  • First dense hidden layer needs input_shape equal to number of input variables; example discussed 10 input variables.
  • Hidden layer example: Dense(64, activation='relu').
  • Regression output example: Dense(1) for one continuous target.
  • Compile step defines backprop/training configuration:
  • optimiser: Adam;
  • learning rate: e.g. 0.001;
  • loss: MSE for continuous prediction;
  • metrics: MAE or other evaluation metric.
  • For classification, output nodes equal number of classes, output activation becomes softmax, loss becomes cross-entropy, and metrics can include accuracy/recall.
  • Loss optimises training; metrics evaluate behaviour. Do not confuse the two.

Scratch implementation / MLP notebook:

  • Lecturer treated MLP and ANN as essentially the same for this class.
  • Notebook avoids TensorFlow/Keras to force understanding of ANN mechanics.
  • Manual network initialisation requires:
  • number of input nodes;
  • number of hidden nodes;
  • number of output nodes.
  • Network is represented as a list of layers; each layer contains neurons/nodes with their weights.
  • First hidden layer weight count: (number_of_input_nodes + 1) × number_of_hidden_nodes; the +1 is bias.
  • Output layer weight count: (number_of_hidden_nodes + 1) × number_of_output_nodes.
  • Example: 2 inputs, 7 hidden nodes, 3 outputs:
  • hidden layer has 7 neurons, each with 3 weights (2 + bias);
  • output layer has 3 neurons, each with 8 weights (7 + bias).
  • Random initialisation used standard uniform random values between 0 and 1.

Manual forward propagation:

  • Define transfer function from weights and inputs.
  • “Inputs” means the previous layer’s outputs — raw features for first hidden layer, hidden-node values for output layer.
  • For each layer:
  • compute each neuron’s transfer value;
  • apply activation;
  • append computed node output;
  • feed those outputs into the next layer.
  • Final output layer node values are the computed prediction values.

Manual backpropagation / training:

  • Required pieces in order:
  1. transfer function;
  2. activation function;
  3. derivative of activation function;
  4. forward propagation;
  5. backpropagation;
  6. update weights;
  7. train network;
  8. initialise network.
  • Backpropagation iterates backward through the network using reverse layer order.
  • It computes errors/deltas for output and hidden neurons.
  • Weight update uses learning rate, neuron delta, and input value from previous layer.
  • Training loop repeats forward propagation → backpropagation → update weights over epochs.

Math / Code

# Core transfer value: weighted sum + bias.
def transfer(weights, inputs):
    z = weights[-1]  # bias term
    for i in range(len(weights) - 1):
        z += weights[i] * inputs[i]
    return z

# Activations from the lecture.
from math import exp, log

def linear(t):
    return t

def sigmoid(t):
    return 1.0 / (1.0 + exp(-t))

def tanh_like(t):
    # use math.tanh in real code; shown conceptually as range (-1, 1)
    import math
    return math.tanh(t)

def relu(t):
    return max(0.0, t)

def leaky_relu(t, a=0.01):
    return t if t > 0 else a * t

def softplus(t):
    return log(1 + exp(t))

def softsign(t):
    return t / (1 + abs(t))

def softmax(ts):
    exps = [exp(t) for t in ts]
    denom = sum(exps)
    return [v / denom for v in exps]
# Gradient-descent update pattern from the lecture.
new_weight = old_weight - learning_rate * gradient

Flashcards (SR)

  • Q: What is the transfer value in a neuron?

    • A: The weighted sum of inputs plus bias: T = Σ(w_i x_i) + b.

  • Q: What is the role of an activation function?

    • A: It transforms the transfer value into a node output and introduces non-linearity/range control.

  • Q: Why is linear activation weak in hidden layers?

    • A: Stacked linear transformations collapse into one linear transformation, so depth adds little expressive power.

  • Q: When is sigmoid appropriate?

    • A: Probability-like binary output or binary classification output layer.

  • Q: When is softmax appropriate?

    • A: Multi-class classification output layer, where probabilities across classes should sum to 1.

  • Q: Why can ReLU be wrong for temperature prediction?

    • A: ReLU cannot output negative values, but temperature can be negative.

  • Q: What is leaky ReLU?

    • A: ReLU variant that keeps a small negative slope for T <= 0 instead of forcing negatives to zero.

  • Q: What is the standard gradient descent update?

    • A: new_weight = old_weight - learning_rate * gradient.

  • Q: What does backpropagation compute?

    • A: Gradients/errors for weights by moving backward from output layer through hidden layers.

  • Q: What is the difference between loss and metric?

    • A: Loss drives optimisation; metrics report/evaluate model performance.

  • Q: How many weights connect 2 inputs to 7 hidden nodes with bias?

    • A: (2 + 1) × 7 = 21.

  • Q: How many weights connect 7 hidden nodes to 3 output nodes with bias?

    • A: (7 + 1) × 3 = 24.

  • Q: What does input_shape=(10,) mean in the Keras example?

    • A: The model expects 10 input features/nodes.

  • Q: Why use inverse transform after MinMax scaling?

    • A: To convert predicted values back from scaled space to the original target scale.
