Focus

Whole session on the recurrent neural network, built up from first principles by repeated Socratic questioning. The spine: an RNN is just an ANN plus recursion in the hidden layer — nothing more exotic. The lecturer's real targets were (1) kill the misconception that RNNs are for "structured data," (2) make precise what the recursion is (one equation with both t and t-1, not a chain of separate H→H connections), (3) write the forward equations with weights shared across time, and (4) set up the RNN↔RL bridge (hidden state ≈ RL state, recursion in the state/action layer) as the entry point to hybrid models.

Key Concepts

  • RNN = ANN + recursion in the hidden layer. Start from the simplest ANN (input → hidden → output, fully connected). The only structural addition is a recursive link in the hidden layer. Keep the mental picture that simple.
  • Occam's Razor for diagrams. When you grab a structure image (even from ChatGPT — "give me a simple RNN diagram"), pick the simplest one and add your own knowledge on top. Simplicity beats complexity in an assignment; a clean diagram you can defend > an impressive one you can't.
  • ANN is static / time-free. For a plain ANN, time doesn't matter: relational/CSV data, a target variable, mini-batches, one epoch = one pass to estimate weights. No time index anywhere.
  • RNN unfolds across time. Every object becomes indexed by t. Inputs become a sequence x_0, x_1, x_2, …; hidden states h_0, h_1, h_2, …; outputs o_1, o_2, …. The pipeline runs along time over time-series / sequential data. The hidden state carries the "story" (memory) forward.
  • What the recursion actually is. h_t depends not only on x_t but also on the previous hidden state h_{t-1} — that dependency is the recursion. It is one equation containing both index t and t-1, not a set of separate hand-drawn arrows H1→H2→H3. (Drawing it as plain connections between hidden nodes is wrong.)
  • Three objects, one recurrent index. The objects are X, H, O. The recursion lives on H (the t-1 term). At a given timestep all objects share the same index: x_t, h_t, o_t.
  • Weight sharing across time. The same weight matrices are reused at every timestep ("you'll use the same"). This is the temporal analogue of a CNN sharing filters across space.
  • One forward pass, memory carried in the hidden layer. The process runs once through the sequence; only the hidden-layer information is propagated forward to the next step.
  • RNNs are for sequential/temporal data — not "structured data." Correcting a student: RNNs are not limited to relational/structured tables. Their home is time-series and sequences: audio, text, video.
  • Univariate vs multivariate (why the course stays univariate). Univariate = one target, effectively a correlation between target and inputs. Multivariate also requires quantifying correlations between the target variables → no clean closed-form equation, needs approximation + large data + heavy compute. That complexity is why the module sticks to univariate.
  • RNN↔RL mapping (the payoff). RL has state, action, reward. The RL state carries data (e.g. a stock close-price series) — it plays the role of the DL hidden state. Recursion can be placed in the hidden/state layer and/or the action stage (one or two recursions). Goal in RL = the optimal action.
  • Different optimisation objects. DL optimises via backpropagation (loss function + optimizer). RL has no activation function; it optimises a reward function instead. Knowing the limits of each and combining them = hybrid models — where bridging DL and RL structures yields genuinely innovative approaches.

Notes (live capture — paraphrased)

Socratic recap ("two sentences on RNN"):

  • Student attempts conflated several ideas; lecturer corrected the key error: an RNN is not for structured data only — it's for time-series / sequential data, processed one step at a time.
  • Agreed working definition: ANN + recursion in the hidden layer. RNN = "recurrent neural network" = ANN with a recursive hidden state. He had students locate exactly where the recursion sits on the diagram (the hidden layer's self/t-1 edge), and rejected the "just connect H1→H2" reading.

Static ANN baseline:

  • Relational data → target variable (o_1/o_2), mini-batch is a subset of the training set, one epoch estimates the weights. Time is irrelevant. This is the contrast object for everything that follows.

Unrolling across time:

  • Treat x, h, o as arrays indexed by time (he wrote them with a tilde to stress "this is an array": h̃ = [h_0, h_1, h_2, …]).
  • Index from an initial point t=0 (x_0, h_0). Move forward: h_1 is affected by x_1 and h_0 → recursion. o_2 ← h_2, and h_2 carries the recursive term from h_1. Repeat.

Forward equations (reconstructed to standard form):

  • Plain ANN hidden unit: h = activation(W·x + b) — generate weights, multiply into the input, add bias, apply activation. Activation can differ per layer.
  • RNN recurrence (the key equation):
  h_t = activation( V · x_t  +  U · h_{t-1}  +  b )

where V = input weight, U = recurrent weight on the previous hidden state, b = bias. (Lecturer used U/V/W loosely as "weights"; the point is the U · h_{t-1} term — that term is the recursion.)

  • Output:
  o_t = activation( W · h_t + b )

Output computation is a minor step — the recurrence is the part that matters.

  • Bias is added at each unit; activation functions may differ between the hidden recurrence and the output.

Applications (corrected from a student's "relational data"):

  • Audio — RNNs (and variants) are a leading family; e.g. speech-to-text (audio → text).
  • Text / NLP — central use case.
  • Video — major use: a video is a sequence of frames over time. Note the contrast: a single image → CNN; image processing is not really an RNN problem, but video is.
  • Variants over time — attention-based, bidirectional, LSTM, etc. All keep the recursion and add machinery to capture more variation/long-range structure.
  • Worked example (sports video): segment a match video into frames (per ~millisecond), use CNN per frame to classify team A vs B, count frames per team → possession ratio; multivariate components on top. Mirrors the Tom & Jerry screen-time demo on Moodle (30s → ~30 frames → CNN detects Tom/Jerry per frame → screen-time prediction).

Hardware-AI tangent (engineer student's question):

  • AI applied to hardware, not just software. NVIDIA cited as the leading example (AI to optimise hardware manufacturing); Intel Ireland and Apple hiring in the space. Concrete uses mentioned: demand forecasting, supply-chain/optimisation. Flagged as a strong, in-demand research direction.

RNN → RL → hybrid models (closing):

  • RL objects: state / action / reward. The state holds data (the close-price series example) → analogous to the DL hidden state.
  • Recursion can live in the state (hidden) layer and/or the action stage — one or two recursions.
  • DL optimisation = backprop (loss, optimizer); RL optimisation = reward function (no activation function). Q-learning named as the popular/traditional method.
  • Knowing both fields lets you see each one's limitations and compensate by combining them → hybrid models.
  • Student tangent: Gaussian Splatting (2D→3D reconstruction, recursively computing points per angle; state-of-the-art in VFX) — lecturer noted it's "recursive data" too. He also referenced Gaussian Mixture Models and Bayesian state-based models from his PhD.
