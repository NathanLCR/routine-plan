RL - Week 1: Introduction to Reinforcement Learning

Focus

Reinforcement learning studies how an agent learns a strategy by taking actions in an environment, observing what changes, and receiving rewards or penalties. Week 1 introduced the intuition before the formal mathematics: RL is less like static supervised learning over a fixed table of features and more like learning what to do next in a changing situation.

Key Concepts

  • Reinforcement learning - learning through trial, feedback, and reward
  • Agent - the decision maker, such as a robot, game player, or software system
  • Environment - the world the agent acts in and receives feedback from
  • Action - a move the agent can choose
  • Observation - feedback about the environment after an action
  • Reward - numerical signal saying whether the action/outcome was useful
  • Strategy / policy - the learned pattern of actions that tends to maximise reward
  • Delayed consequences - an action can be good because of future states, not only immediate gain
  • State/action space - the set of possible situations and possible actions
  • Business feasibility - an AI solution can be technically possible but too expensive to justify

Notes

Why RL is different from static ML:

  • Classical machine learning often starts with a fixed table: columns, features, labels, and a model

    • that learns relationships from those examples.

  • CNNs work with static image data by learning graphical filters over pixels, then combining detected

    • patterns through layers.

  • Reinforcement learning deals with changing situations: games, robotics, movement, and strategy.
  • The key question becomes: what action should the agent take now so that later outcomes are better?

Agent-environment loop:

  • The agent chooses an action.
  • The environment changes because of that action.
  • The agent receives an observation about what happened.
  • The agent receives a reward or penalty.
  • The agent updates its behaviour so future actions are more likely to produce high reward.

Game examples:

  • Chess is a useful RL-style intuition because the board changes after every move.
  • A move such as E2-E4 is not only about immediate points; it can be good because it creates better

    • future positions.

  • A simple point-counting algorithm can fail strategically: it may capture a valuable piece while

    • moving into a worse board position.

  • RL is therefore connected to strategy, sequences of actions, and delayed reward.

Robotics example:

  • A robot on a production line can learn which hand movements catch or move parts successfully.
  • Some attempted positions or movements fail, receiving low reward.
  • Successful movements receive higher reward.
  • Over repeated trials, the robot learns the useful region and movement sequence.

Computer vision and industrial AI example:

  • The lecturer contrasted technical possibility with business reality.
  • An industrial camera could detect malformed rubber/medical parts and stop a production line.
  • This could replace or support manual quality control, but the business must still decide whether

    • the implementation cost is justified.

  • Another example involved camera detection in bank offices: the prototype might work, but if the

    • total deployment cost is far higher than the annual loss, the AI project is not worthwhile.

Limits and risks introduced:

  • The number of possible states and actions can become very large.
  • A reward function that overvalues immediate gain can produce bad strategy.
  • RL can be computationally expensive because it needs many trials.
  • The environment must be constrained enough that learning is practical.
  • Technical feasibility is not the same as useful deployment.

Math / Code

No formal equations were introduced in this lecture. The useful mental model is the loop:

agent observes state
agent chooses action
environment changes
agent receives observation and reward
agent updates future action choice
repeat

Flashcards

  • Q: What is the agent in reinforcement learning?

    • A: The decision maker that chooses actions, such as a game player, robot, or software system.

  • Q: What is the environment?

    • A: The external system or world that changes in response to the agent's actions.

  • Q: What is a reward?

    • A: A feedback signal that tells the agent whether the outcome of an action was good or bad.

  • Q: Why is RL different from supervised learning?

    • A: Supervised learning learns from fixed labelled examples; RL learns through actions, feedback, and changing future states.

  • Q: Why can an immediate high-value move be bad in chess?

    • A: Because it may create a worse future board position even if it gains points immediately.

  • Q: What does the robot production-line example show?

    • A: RL can learn action sequences through repeated trials where successful movements receive higher reward.

  • Q: Why might a technically successful AI prototype still fail as a business project?

    • A: Deployment cost can exceed the value of the loss or problem it solves.

  • Q: What should Nathan read first after this lecture?

    • A: The beginning of Sutton and Barto's Reinforcement Learning: An Introduction.
