Key Concepts

  • Return (discounted) — G = r₀ + γr₁ + γ²r₂ + … + γⁿrₙ. The agent maximises total discounted return, not the biggest immediate reward.
  • Discount factor γ — down-weights later rewards by γ^(step). Two reasons: (1) prefer faster paths to the same reward (fewer steps ⇒ less discounting ⇒ higher value); (2) but not always — a longer path with a higher total return still wins (chess example: a fast capture isn't the best move if it doesn't lead to mate).
  • Policy (π) — the strategy mapping state → action. Variants: greedy (always highest known reward), safe (avoid negative reward), random, and ε-greedy (mix of random exploration + greedy exploitation).
  • Deterministic vs stochastic policy — deterministic: one action gets probability 1, all others 0. Stochastic: a probability distribution over actions (e.g. 0.7/0.3).
  • V vs Q — State Value V(s) = expected return from being in state s; State-Action Value Q(s,a) = expected return from taking action a in state s. Q is the basis for action selection.
  • Optimal policy — finding it is the RL problem. Defined by states + actions + rewards; "optimal" is the recurring word (optimal control, optimal models…).
  • DQN — neural net replaces the Q-table; maps state → Q-value per action. Needed because real-world state×action spaces explode (the in-class binning example: 4 params × ~10 bins ⇒ ~100M combinations).
  • Experience replay — store (s, a, r, s') tuples, train on random batches to break the sequential correlation that breaks standard NN training assumptions.
  • Target network — a second, frozen copy of the Q-network that predicts the target Q-value; Q-network weights are copied to it every T steps. Stabilises training (avoids chasing a moving target).
  • Policy Gradients — a net that learns the optimal policy directly: input state → output probability distribution over actions; sample an action from it. No Q-table, no argmax.
  • PPO (Proximal Policy Optimization) — the policy-gradient method demoed on CartPole via an MLP policy; the lecturer flagged it has multiple hyperparameters to tune (relevant to the CA's "≥2 variants" requirement).

Notes (live capture)

Return & discount (slides 8–18):

  • Return = r₀ + γr₁ + γ²r₂ + … + γⁿrₙ. With γ=0.5 the second-step reward is halved, third quartered, etc.
  • Worked intuition: 2 doors, one 2 steps away, one 20 steps away, same reward → the near door has higher discounted return.
  • Counter-case: rewards [2, 0] vs [0, 2] over two steps — early reward wins under discounting, but if a longer path yields a higher total (20 here, 0 there summing to 150) the longer path is better. Discounting biases toward early reward; it is not always the optimum.

Policies (slides 11–21):

  • Policy = lookup table of which action to pick per state when states/actions are few.
  • Stochastic policy = distribution per state (e.g. P(left)=0.7, P(right)=0.3); deterministic = a single action with P=1.
  • Optimal policy after training is the deliverable of the whole RL problem.

Q-value update (slides 22–40):

  • Why "Q-tables": Q = quality/value of the next step. Fill them in Python via iteration over episodes.
  • Notation shorthand on slides: Q2, Q6 instead of Q(2,2), Q(6,4).
  • The update is TD/bootstrapping: step back from the terminal state, propagate reward to earlier state-actions over many episodes; different episodes (shown in colours) give better/worse estimates that converge.
  • Worked example (slide "Update the Q"): S1 →(a1, R1=2)→ S2; S2 has a2/a3/a4 with Q2=3, Q3=4, Q4=7; the current Q(S1,a1) cell gets updated from the max of S2.

DQN (slides 43–69):

  • Workflow: replay picks an ε-greedy action → execute → save (s,a,r,s') to replay memory → sample random batch → Q-network predicts Q(s,a) on current state, target network predicts r + γ max Q(s',a') on next state → compute loss → backprop to Q-network only → every T steps copy Q-net weights → target net.
  • Difference vs a normal NN: standard supervised data is i.i.d.; here you must simulate/replay the environment and decorrelate samples, hence replay + a separate target net.
  • Lecturer's framing: DQN "uses a loss function rather than" a hand-derived table update — structurally supervised-learning-like.

Policy Gradients / PPO (slides 70–92):

  • Net outputs a probability distribution over actions; action chosen by sampling.
  • Training data gathered from actual experience; at episode end the whole episode batch is fed in; policy net weights stay fixed during loss computation.
  • Discounted Return per sample = weighted sum of rewards; take log P(action actually taken), weight by the discounted return, sum the negative quantities across states → that's the loss (maximise return ⇒ minimise negative log-prob × return).
  • Code demos: Q-learning (Gymnasium Taxi-v3, ε-greedy, prints Q-table); stock trading (TensorFlow/Keras dense layers, agent looks back 5 days → buy/hold/sell — "random prices, not a business tool"); PPO on CartPole (MLP policy, tune ≥2 hyperparameters).

# DQN target (what the TARGET network computes; Q-network is trained toward it):
#   y = r                       if s' terminal
#   y = r + γ·max_a' Q_target(s', a')   otherwise
#   loss = (Q_online(s,a) − y)^2 ; copy Q_online -> Q_target every T steps

# Policy-gradient (REINFORCE-style) loss the lecturer described:
#   L = − Σ_t  log π(a_t | s_t) · G_t      # G_t = discounted return of the sample

Flashcards (SR)

  • Q: Write the tabular Q-learning update rule.

    • A: Q(S,A) ← Q(S,A) + α(R + γ·max_a Q(S',a) − Q(S,A)). The bracket is the TD error; the target R + γ·max Q(S',a) is grounded in actual data.

  • Q: Why does DQN need a second (target) network?

    • A: To stop the network chasing a moving target. The target net is a frozen copy that supplies the Bellman target; Q-net weights are copied to it every T steps for stability.

  • Q: Why experience replay?

    • A: Sequential transitions are correlated, which breaks NN training assumptions. Sampling random batches from stored (s,a,r,s') tuples decorrelates the data.

  • Q: Deterministic vs stochastic policy?

    • A: Deterministic = one action has P=1 (rest 0). Stochastic = a probability distribution over actions per state.

  • Q: How do policy gradients differ from DQN?

    • A: PG learns the policy directly — net outputs action probabilities and you sample — instead of learning Q-values and taking argmax. Loss = −Σ log π(a|s)·G.

  • Q: Two reasons for the discount factor γ, and the caveat?

    • A: (1) Prefer fewer-step paths to the same reward; (2) make math/returns finite & prioritise early reward. Caveat: a longer path with higher total return can still be optimal — discounting biases, it doesn't decide.
