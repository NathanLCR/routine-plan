Key Concepts

  • Topic modelling — unsupervised theme discovery: you specify N topics and M words/topic; the model returns topic 0…N−1 each as its top-weighted tokens, for you to interpret. No labels.
  • Document = mixture of topics — each doc gets a topic-probability distribution (e.g. 20% topic 1, 5% topic 6); assign it the highest-probability topic, but mixtures are normal.
  • LDA (Latent Dirichlet Allocation) — Blei, Ng & Jordan, 2003. Generative probabilistic (3-level hierarchical Bayesian) model; "probability of this collection of words occurring together." Words can appear in multiple topics (fuzziness). The modern baseline to compare against.
  • LSA (Latent Semantic Analysis) — Deerwester et al., 1990. Linear-algebra based: build TF-IDF term×document matrix → SVD → keep top topic-importance components. Older, but sometimes wins (it beat LDA on the Troubles-era Irish documents — wordy/descriptive text, longer docs).
  • NMF (Non-negative Matrix Factorisation) — 1994; factorises term×document into term×topic and topic×document (all non-negative). Also common in collaborative-filtering recommenders. Good for compact, clear topics.
  • BERTopic — transformer-based topic modelling (~2020), built on BERT's encoder side. The dominant transformer option; the headline modern-vs-traditional comparison is BERTopic vs LDA.
  • Coherence — quantitative measure of how human-interpretable topics are; the score you use for comparative research. c_v-style guide she gave: 0.4–0.55 acceptable, 0.55–0.65 good (reliable baseline), 0.65–0.75 very good, 0.75–0.8 excellent/rare, >0.9 almost always unrealistic / suspect overfitting. (UCI = co-occurrence in a sliding window over an external corpus; UMass = document co-occurrence.)
  • pyLDAvis — Sievert & Shirley, 2014. Standard topic visualiser: MDS layout of topics (left) + tunable relevance metric reordering top words (right). Default 100% relevance = pure frequency. Exportable to HTML or inline in Jupyter.
  • PCA vs SVD — PCA = dimensionality reduction via orthogonal (uncorrelated) components ordered by explained variance; PCA is a special case of SVD. PCA needs normalised input + covariance matrix; SVD doesn't and is often more numerically stable.
  • Clustering — unsupervised grouping of vectorised text so intra-cluster items are more similar than inter-cluster. Names are arbitrary (cluster 0/1/2). Uses: exploration, label generation for unlabelled corpora, pre-processing for classification.
  • k-means — partitive/centroid method: pick k, assign points to nearest centroid (usually Euclidean), recompute centroids, iterate to convergence (max-optimisation); restart max_runs times with new random seeds. Assumes globular clusters, needs k known, sensitive to outliers; normalise first.
  • Hierarchical (agglomerative) clustering — merges nearest items first, producing a dendrogram; short branches = low variance (merged early), long branches = high variance (merged late).
  • Elbow method — run k-means for k=2…10, plot within-cluster sum of squares vs k; the "elbow" (sharp bend) suggests optimal k.
  • Similarity / distance metrics — Minkowski p-norm (p=2 Euclidean, p=1 Manhattan; absolute values differ by p but relative ordering is stable); Mahalanobis (std-devs from a distribution, rescales by covariance); Jaccard (|intersection|/|union| of token sets, 0–1); Levenshtein (edit distance between strings, e.g. kitten→sitting = 3 edits); cosine (dot product / product of norms — the go-to for text vectors).
  • UMAP — 2020, graph-theory-based dimensionality reduction; projects high-dim embeddings (e.g. 384-d) to 2-D for visualisation; shown to beat t-SNE. Colour points by cluster to sanity-check structure.
  • RAG (previewed) — vectorise the query, store doc/answer vectors in a vector DB or graph DB (Neo4j), retrieve by cosine similarity; the LLM supplies language, proprietary knowledge stays in the external store (not fine-tuned in).

Notes (live capture)

Topic modelling — workflow & LDA demo (20 Newsgroups):

  • Same pre-processing as any text: clean punctuation, lowercase, lemmatise (not stem — caring→care, keeps meaning), stop-word removal, tokenise.
  • Corpus: 18,846 news articles, 20 categories. Built with Gensim. filter_extremes (keep tokens in ≥15 docs, drop ultra-common) cut vocabulary 51,144 → 6,221 tokens before passing to LDA.
  • LdaModel hyperparameters: num_topics=10, print 8 words/topic; chunksize=100 (laptop-friendly, updates per chunk); passes=10 (≈ epochs; >50 overfits, 10 is the sweet spot); alpha='auto' (doc-topic prior), eta='auto' (topic-word prior), per_word_topics=True (also returns per-word topic assignment).
  • Output is a ranked token list per topic (each token weighted) — "a bit like k-means cluster IDs," not meaningful names; you interpret the theme.
  • Coherence: built via Gensim CoherenceModel on the fitted model. Demo scored 0.556 → "solid, above-average baseline" to improve via tuning and by comparing algorithms.
  • Visualise with pyLDAvis — far more usable than the raw token lists; play with the relevance slider to see which words best characterise each topic.

Algorithm comparison (the research framing):

  • LDA = probabilistic baseline; LSA = SVD/linear-algebra (better for descriptive topics & longer docs); NMF = compact/clear topics; BERTopic = transformer. "Different algorithms win on different data — experiment, measure coherence, visualise."
  • Transformers context: she opened Vaswani et al., 2017 "Attention Is All You Need" (encoder–decoder). BERT uses the encoder; GPT uses the decoder (we'll build a GPT from scratch later). BERTopic bolts topic modelling onto BERT's encoder. Swapping the final layer of the same transformer backbone turns next-word prediction into classification, topic modelling, etc.
  • Graph-based topic modelling (Tietz/co-author et al.): build a co-occurrence graph (edges = times two tokens occur within a ~5–10-word context window) and run community detection (Louvain) → topics. Completely novel angle; co-occurrence graph is next week's topic. Examiners reward novelty.
  • Labelling-by-topic-model research idea (and its pitfall): use LDA vs BERTopic to label an unlabelled corpus, then classify; benchmark against true hand-annotated labels. A past student did the comparison but had no ground-truth labels, so the examiner comment was: take a dataset that does have labels, ignore them, label with each method, and benchmark against truth. Do it the right way.

Federalist Papers — topic results (LDA, 4 topics):

  • Each letter turned out to be a single clear theme (no mixing here, small corpus): Paper 18 → topic 0 (Ancient Greece: Macedon, Achaeans, Greece); Paper 17 → topic 1 (federal vs state powers: states, citizens); Paper 14 → topic 2 (forms of government: states, government, union, republic, democracy); Paper 5 → topic 3 (Britain's division into nations).

Clustering:

  • "Text is just representation — once vectorised, apply standard ML clustering." Cluster IDs are arbitrary; use to find structure or generate labels for unlabelled corpora.
  • Use cases: group medical discharge notes by symptom/disease (ICD option — cluster the notes, see if they split by disease type even though you have the ICD label); group documents by writing style (Federalist authorship).
  • k-means mechanics: pick k random centroids → assign each point to nearest (Euclidean) → recompute centroids (point with min sum-of-squared-error within group) → reassign → iterate (max-optimisation / until centroids stop moving) → score avg within-cluster SSE; restart max_runs times from new random seeds and keep the best. Normalise so features share scale.
  • Elbow curve (shown on Iris): plot within-cluster SSE for k=2…10; bend at k=2/3 for Iris. Used to choose k when you don't know the number of groups.
  • Hierarchical: dendrogram, nearest pairs merged first; branch length = variance. Different family from centroid-based k-means.
  • sklearn offers many more (density-based, spectral, agglomerative) — experiment; interpret which gives the most sensible groups.

Similarity metrics (the real choice in clustering):

  • k-means / kNN typically Euclidean (Minkowski p=2) or Manhattan (p=1). Text usually cosine. Jaccard for token-set overlap. Levenshtein for string edit distance. Mahalanobis for comparing across distributions/lengths.
  • Cosine + RAG (dissertation-relevant): vectorise a question, store vectors in a vector/graph DB (Neo4j), retrieve the most cosine-similar stored vector, return its answer. RAG keeps proprietary knowledge in the external store, not in the fine-tuned LLM.

Federalist Papers — authorship via clustering (the case-study payoff):

  • Known: Jay wrote 3,4,5; Madison wrote 14; Hamilton wrote 17; Paper 18 suspected Madison–Hamilton collaboration. Task: text-mining evidence for the collaboration.
  • Method: BoW TF-IDF → k-means with k=2. Result: cluster 0 = Jay's papers; cluster 1 = Hamilton + Madison + Paper 18 → evidence Paper 18 was the joint Hamilton–Madison work (similar writing style/tokens cluster together).

UMAP visualisation:

  • Embed sentences (384-d) → UMAP to 2-D → plot; semantically similar texts land together (cats/kittens cluster; coffee/espresso/latte cluster; LLM/BERT/deep-learning cluster). Colour by cluster to judge whether cluster assignments are meaningful. Graph-theory based; outperforms t-SNE (2020 paper).

Self-test Q&A

  • Q: What does topic-modelling coherence measure, and what's a "good" baseline?

    • A: How human-interpretable the topics are. ~0.55–0.65 is good/reliable; >0.9 is unrealistic and suggests overfitting.

  • Q: LDA vs LSA — different mathematical underpinning?

    • A: LDA = generative probabilistic (Bayesian) "which words co-occur"; LSA = linear algebra, TF-IDF matrix factorised by SVD. LSA can win on longer/descriptive text.

  • Q: Distinctive feature of LDA vs the others?

    • A: Fuzziness — a word can belong to more than one topic; documents are topic mixtures.

  • Q: Why normalise before k-means, and which distance does it use?

    • A: So features share scale; k-means typically uses Euclidean (Minkowski p=2) distance.

  • Q: Cosine similarity = 1 vs 0 vs −1?

    • A: 1 = vectors parallel / most similar; 0 = orthogonal / unrelated; −1 = opposite. (See Flags — lecturer stated this backwards.)

  • Q: How do you turn an unlabelled corpus into a labelling experiment properly?

    • A: Take a dataset that has truth labels, hide them, label with LDA and BERTopic, run the same classifier on each labelling, and benchmark both against the truth labels.

  • Q: How did clustering support the Paper-18 authorship claim?

    • A: TF-IDF + k-means (k=2) put Jay alone in one cluster and Hamilton+Madison+Paper 18 in the other → stylistic evidence of Hamilton–Madison collaboration.
