Key Concepts

  • Co-occurrence graph — tokens are nodes; edge between two tokens that appear within N words of each other; edge weight = co-occurrence count. Built with NLTK (tokenize, extract keywords, combinations of keyword pairs) + NetworkX (add_edge with weight).
  • Graph-based topic modelling — run Louvain community detection over a co-occurrence graph → topics. Novel comparator vs LDA (probabilistic) and BERTopic (transformer) for research.
  • Knowledge graph / GraphRAG — Neo4j now auto-builds a knowledge graph from a PDF; enables comparing vector-RAG vs graph-RAG for QA chatbots.
  • Word cloud — per-class token clouds for quick visual separability check (her Amharic-sentiment student example: classes visibly differed even when she couldn't read the script).
  • Frequency distribution — Yellowbrick FreqDistVisualizer + sklearn CountVectorizer; plots top-50 tokens. Expects count-vectorized input (no normalisation done for you); strip stop words first (stop_words='english'). Hobbies corpus: cooking → pasta/pan/broccoli/pepper; gaming → players/developers/character/support.
  • PosTagVisualizer (Yellowbrick) — colours text by part of speech; quality is domain-dependent (decent on a recipe, poor on a nursery rhyme). Key-phrase extraction = POS tags + a grammar (regex found by heuristics; fails on ungrammatical text).
  • Dimensionality reduction for text — PCA, Linear Discriminant Analysis, Doc2Vec compress dimensions; cost: you lose the original features (terms/phrases) for interpretation.
  • t-SNE — nonlinear 2-D/3-D embedding via pairwise-similarity probability distributions; the classic "published-paper" projection. Computationally heavy → run SVD/PCA first (Yellowbrick TSNEVisualizer does TruncatedSVD→50 components by default; decompose="pca" available). Feed KMeans.labels_ or corpus.target into fit() to colour by cluster/class.
  • UMAP — graph-theory-based reduction; outperforms t-SNE in many contexts; use for class-separability checks (see Flags re: year).
  • Classification heatmap (Yellowbrick ClassificationReport) — per-class precision/recall/F1 as a colour grid; spots weak classes at a glance (GaussianNB struggled with "books" false negatives; SGD with "gaming" false positives).
  • Confusion matrix heatmap (Yellowbrick ConfusionMatrix) — predicted × actual counts; shows which classes confuse the model (LogReg fine on sports/gaming, weak elsewhere). Set application-specific benchmarks, not headline F1.
  • SHAP — model-agnostic interpretability for black-box models (ensembles, deep learning); "almost standard now" for paper submissions. SHAP value ≈ 0 → feature inert; sum of per-feature SHAP values moves the raw score, converted to probability via sigmoid 1/(1+e^(−raw)). Plots: beeswarm (global, per-example dots), mean-|SHAP| feature importance, force plot (single prediction decomposed feature by feature), dependence plot (e.g. capital gains > ~$5–6k → SHAP jumps). For text: works on BoW token features ("absolutely fantastic movie" → per-token contribution to sentiment).
  • Entity resolution — Dorothy's "Toto"/"little dog"/"dog" are one entity; must be resolved before character co-occurrence networks make sense. A separate, real problem.
  • Spring layout (NetworkX) — heavier-weighted edges pull nodes closer (Wizard of Oz character network); Neo4j's D3 view spaces everything equally, so NetworkX wins for this.
  • RNN — recurrent net for sequences: output at step t mixes current input with memory of previous steps. Problem shapes: many-to-one (sentiment), one-to-many (image captioning), many-to-many (translation). Handles variable-length input, order, long-term dependencies, shared parameters across positions.
  • tanh — standard RNN activation, maps to (−1, 1) (vs ReLU in feed-forward ANNs).
  • Vanishing / exploding gradients — backprop-through-time products blow up or shrink to zero → effective context window is tiny; the central RNN failure mode.
  • Fixes timeline — gradient clipping + better initialisation + ReLU (2010s); LSTM 1997 (forget gate, additive gradient path); GRU 2014 (simplified, cheaper LSTM); Transformers 2017 (Vaswani et al., "Attention Is All You Need") drop recurrence and convolution entirely → wide context.
  • Temperature — divides logits before softmax: low (0.2–0.5) → near-deterministic, repetitive; ~0.7–0.9 → "Shakespeare-like"; ≥1.3 → creative/noisy. The char-RNN demo generated at 0.85.
  • Logits → softmax — model outputs a raw score per vocabulary item; softmax converts to next-token probabilities; largest logit = most probable token. Classification with an LLM = same backbone + a trained classification head (spam/ham demo coming).

Notes (live capture)

Co-occurrence graphs:

  • Tokenize + lowercase → extract keywords → itertools.combinations(keywords, 2) → NetworkX nodes/edges, weight = co-occurrence count within the window.
  • Run Louvain over the graph → effective topic modelling. Research framing: LDA (probabilistic) vs BERTopic (transformer) vs co-occurrence+Louvain (graph) on one corpus = "quite novel."
  • Same idea powers character networks (Wizard of Oz): edge = characters within N words; spring layout pulls Dorothy/Toto/Tin Woodman tight, Monkey King far. Underneath it's just a big co-occurrence matrix → linear algebra (factorisation) and matrix heat maps (characters alphabetical, darker = more interactions) apply.
  • Caveat before plotting: entity resolution (Toto = "little dog" = "dog").

Model diagnostics:

  • Pipeline she showed: TF-IDF vectorize → SVD → t-SNE → k-means (k=5) → colour points by cluster; clusters separate nicely on the hobbies corpus. For labelled data (gender), colour by class label instead → separability check.
  • Yellowbrick ClassificationReport and ConfusionMatrix: instantiate with the sklearn model + class names, then fit / score / poof. Heat-mapped report > printed report for spotting per-class failures fast.
  • Cross-validation is "the gold standard"; report mean ± std across splits.

SHAP walkthrough (UCI Adult, XGBoost, 200 trees depth 5, AUC 93.04):

  • explainer = shap.TreeExplainer(model) → shap_values = explainer(X_test). Plain shap.Explainer auto-picks.
  • Beeswarm: wide spread around 0 = influential feature (capital gain, relationship, age, education); tight at 0 = inert (race, country, sex).
  • Single example: expected base value −1.189 (≈23–24% positive via sigmoid); per-feature contributions stack to +7.657 → P(income>50k) ≈ 99.8%. Force plot shows the same horizontally.
  • Dependence plot: capital gains ≤ ~$5k ≈ flat; above $5–6k SHAP jumps.
  • For text: apply to a BoW model and you get per-token impact on the prediction — exactly the interpretability story for CA1 (and why keeping one BoW representation in the grid is strategically smart).

RNN mechanics:

  • Memory a_t is "just a really complex matrix of weights": current input weighted + previous activation weighted, through tanh. Noun-tagging example: seeing "my name is ___" → previous context pushes y₄ → 1 (noun).
  • Trained by backprop through time → vanishing/exploding gradients; practically can't unroll far (she said ~4 steps before it degrades — heuristic, not a law). That ceiling on context is the reason transformers won.
  • History: n-gram language models (P(wₙ | n−1 previous)) → ANNs (no order) → CNNs (spatial) → RNNs (order) → LSTM '97 → GRU '14 → attention '17.

PyTorch char-RNN demo:

  • torch.nn.RNN (also .LSTM, .GRU — same API). Character-level: raw text of 604 chars, vocab 40 (letters + punctuation).
  • Hyperparams: sequence length 64 (input = chars 1–64, target = next char — same scheme LLMs train on), batch 64, hidden layer 128 neurons, 40 epochs.
  • Output = tensor of 40 logits → softmax → sample with temperature 0.85 → 300-char generation. Result was passable fake Shakespeare ("sounds like Shakespeare, even if it's meaningless").
  • Karpathy's 2015 blog post ("The Unreasonable Effectiveness of Recurrent Neural Networks") as background: char-RNNs generating Paul Graham essays, Shakespeare, Wikipedia, LaTeX, Linux source.

Flashcards (SR)

  • Q: What is a co-occurrence graph and what clustering algorithm turns it into topics?

    • A: Nodes = tokens, weighted edges = times two tokens appear within N words; Louvain community detection over it ≈ topic modelling.

  • Q: Why does the lecturer dismiss accuracy as a metric?

    • A: It's (TP+TN)/all — a model can miss virtually every positive case and still score high if negatives dominate; interpret per-class precision/recall/F1 + confusion matrix instead.

  • Q: For blog gender, which metrics matter and why?

    • A: Sensitivity AND specificity equally (plus per-class P/R/F1 and AUC) — there's no privileged positive class, unlike fraud or churn.

  • Q: What's the interpretability trade-off between BoW and embeddings?

    • A: BoW keeps tokens as features → SHAP per-token analysis possible; embeddings capture meaning and usually perform better but lose the token, so no SHAP.

  • Q: What does a SHAP value near zero mean, and what plot shows global feature influence?

    • A: The feature barely affects that prediction; the beeswarm plot — wide spread around 0 = influential feature.

  • Q: Write the RNN update equations.

    • A: a_t = tanh(W_aa·a_{t−1} + W_ax·x_t + b); y_t = softmax(W_ya·a_t + b_y).

  • Q: Why do plain RNNs fail on long contexts, and name the fixes in order.

    • A: Vanishing/exploding gradients in backprop through time; gradient clipping/better init/ReLU → LSTM (1997, forget gate) → GRU (2014, simplified) → transformers (2017, no recurrence).

  • Q: What does temperature do at generation time?

    • A: Divides logits before softmax — low T sharpens toward the top token (repetitive), high T flattens the distribution (more creative/noisy).

  • Q: Why run SVD/PCA before t-SNE?

    • A: t-SNE is computationally expensive; reduce dimensions first (Yellowbrick's TSNEVisualizer defaults to TruncatedSVD, 50 components).

  • Q: Correct F1 formula?

    • A: F1 = 2·(precision·recall)/(precision+recall) — the slide had it inverted.
